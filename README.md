# WorkNiu · 打工牛马工作台

写给打工人的一块自我量化工作台。纯前端、零依赖、数据完全留在本地。

## 为什么是它

上班最大的消耗不是累，是「不知道自己在为什么」。WorkNiu 把抽象的工作时间换算成看得见的回报：今天到目前赚了多少、相当于几杯冰美式、还差几个番茄下班——用具体的价值感替代麻木的倒计时。

## 功能一览

### 收益与电量
- 选择薪资时段后，页面实时显示「今日已赚」，并按工作进度推算下班时刻的收益
- 收益同时换算成奶茶、咖啡等实物等价，让「我在挣什么」变得具体可感
- 精力电量条随工作时长消耗，一眼看出今天还剩多少油水

### 任务四象限
- 按重要与紧急分层管理待办，拖拽即可调整象限，只聚焦当下该做的那件事
- 任务支持备注、图片附件、截止日期与番茄钟计数
- 已完成任务自动进入独立清单，隔天自动收起（可关闭），支持搜索、查看详情、单条删除
- 任务数据可导出 CSV，时间范围自定义，想复盘哪段就导哪段

### 番茄钟
- 专注计时可选 15 / 25 / 45 / 60 分钟，统计今日与累计专注时长
- 支持弹出小窗浮在桌面，随时查看当前进度

### 倒数日
- 自定义倒数事项，支持按天 / 周 / 月 / 年重复，按最近到期自动排序
- 法定节假日自动倒数：内置国务院年度放假安排，自动显示最近的假期，结束后切换下一个；每年官方公布新安排后自动更新，未公布期间按元旦兜底
- 支持通过二级页开关显示与查看全部假期列表

### 数据管理
- 一键导出 / 导入 JSON 备份，换设备或换浏览器时数据可以带走
- 本地自动备份：绑定一个本地文件后，数据每次改动实时写入，不用惦记着手动导出
- 存储占用实时显示，支持一键清理图片缓存（文字记录保留）

### 牛马人格
- 自定义一个自嘲式人设（全脂 / 脱脂 / 脆皮 / 电子…），页面上陪伴你打工，用幽默消解班味

## 设计原则

- **隐私优先**：全部数据仅保存在本地浏览器，无账号、无云端、无追踪，不上传任何信息
- **零依赖**：单个 HTML 文件，无框架、无构建、无网络请求，打开即用
- **多端适配**：桌面、平板、手机同一份代码自适应

## 数据安全说明

所有数据存于浏览器的 localStorage，不依赖任何服务器。正常使用下数据是稳定的，但以下情况会导致丢失：

- 清理浏览器缓存与站点数据
- 开启了「退出时自动清除浏览数据」类设置
- 使用无痕 / 隐私模式

右上角菜单的「数据安全」提供三层保障：

1. **导出备份**：生成 JSON 文件存到任意位置，换设备或清理浏览器前先导一次，数据文件很小（无图片附件时通常不到 100KB），存进网盘或发给自己即可
2. **导入数据**：从备份文件一键恢复全部数据
3. **本地自动备份**：绑定电脑里的一个本地文件，此后每次改动实时写入，彻底告别「忘记导出」。绑定状态会持续检测，备份文件被手动删除时自动解除绑定并提醒（需要 Chrome / Edge 等支持的浏览器）

三者配合使用最稳：开一个本地自动备份兜底，重要节点（换设备、大改动前）再手动导出一份存到网盘。
